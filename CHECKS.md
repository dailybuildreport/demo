# Проверка DSFlow

> Выпуск `2026.09.30-dsflow.18`: аудит унификации, внесённые изменения и повторная проверка обоих объектов — в [AUDIT.md](AUDIT.md). Ниже — проверки выпуска dsflow.17.

Дата: 30.09.2026. Версия: `2026.09.30-dsflow.17`.

## Сохранность исходников

Исходные данные и ключевые расчёты сравнивались с HTML из двух архивов.

- «Огни»: массивы всех 45 сводок, 23 целей, 8 испытаний и 83 событий совпадают с исходником 29.09. Исходные функции графиков, журнала, рисков и отчётов сохранены; ежедневные показатели теперь находятся в карточках работ и исходном производственном разделе.
- «Раменки»: обзор обёрнут в общие стили рабочего стола. Удалена регистрация отдельного worker, пути исходных библиотек чтения файлов заменены на локальные. Расчёты и ключи `rmk.*` сохранены.
- Подтверждённые локальные добавления «Огней» накладываются поверх всех 45 исходных сводок. Автоматический тест проверяет новую дату, объединение двух изменений за один день и сохранность исходной истории.
- Данные проектов и встроенные фотографии не пересчитывались и не заменялись.
- Переданные рендеры скопированы без изменений и показаны только на карточках соответствующих объектов; они не подменяют фотографии хода работ.

## Автоматические проверки — пройдены

- Разбор всех встроенных и общих JavaScript без синтаксических ошибок.
- Наличие всех локальных ссылок HTML, шрифтов, значков manifest; размеры обычных и maskable-значков.
- Импорт 1 488 работ из переданного MPP, четырёх вех и 932 строк со связями; стоимость исключена из публичного JSON.
- Один manifest и один service worker для всего пакета.
- Наличие каждого файла из списка автономного кэша.
- Главная, «Огни» и «Раменки» возвращают собственные страницы без сети, включая адреса с параметрами и размещение в подпапке.
- Адреса проектов без слэша перенаправляются на канонический адрес, сохраняя параметры.
- При ответе сервера 5xx возвращается копия нужного проекта. Ответ 404 не маскируется.
- Запись HTML в кэш не задерживает показ сетевого ответа; ошибка записи кэша не ломает страницу.
- Worker не перехватывает API, неизвестные адреса, внешние источники и POST, сохраняет кэши других приложений.

Проверки worker выполнялись в программной модели Fetch/Cache API. Отдельно сделана проверка в настоящем браузере ниже.

## Проверка единого рабочего стола в браузере

- Экран выбора проектов проверен на desktop и при ширине 390 px: новый горизонтальный рендер «Огней» и рендер «Раменок» заполняют области своих карточек, горизонтальной прокрутки нет.
- Обзор двух объектов повторно сравнен при ширине 1280, 1040, 820 и 390 px. Ширина боковой панели — соответственно 236, 76, 76 и 0 px; высота плашки «Ход работ» совпадает: 130, 130, 198 и 251 px. Сетка KPI совпадает: 3, 2, 2 и 1 колонка. Горизонтальной прокрутки нет.
- Открыты общий экран проектов и оба рабочих стола. Проверено одинаковое расположение трёх главных карточек, графика, календаря и фотохроники, общий стиль боковой панели и навигация на мобильной ширине 390 px без горизонтальной прокрутки.
- Обзор «Огней» больше не показывает суточные числа БНС и СВГ как главные KPI; бюджет и фото остаются пустыми до поступления данных. Общая готовность не рассчитана из несопоставимых объёмов работ.
- Проверен путь «Обзор» → «Реализация» → «Нулевой цикл» → «БНС» и путь из Ганта обратно в карточку. Карточка БНС показывает 96 из 262 свай, план 110, отставание 14, темп 11 свай в неделю, прогноз 16.12.2026, историю и семь последних сводок. Оригинальный производственный раздел, его графики и прогноз доступны.
- Проверены поиск `#66` среди 1 487 отображаемых строк Ганта (сводный корень не показывается), исходные даты 07.08–10.12.2026 и предшественник 65. Календарь показывает окончание СВГ в октябре 2026. Структура содержит оперативные виды работ, для которых нет однозначной строки в ГПР.
- «Раменки» открываются в общей оболочке; фактическая готовность 37% и прогноз +29 дней сверены с их исходным dashboard. Его бизнес-расчёты не изменены.
- Версии в адресах CSS/JS и общем worker обновлены, чтобы открытый ранее PWA получил новый интерфейс.
- На мобильном экране «Огней» проверено открытие общего окна «Данные ИИ» из быстрой кнопки. Раздел фотохроники показывает пустое состояние и кнопку загрузки. Само сохранение реальной фотографии в браузере не проверялось, поскольку фотографии площадки для этого действия не переданы.
- Тест на физическом iPhone и размещение на домене ещё не выполнялись.

- Сформирован суточный отчёт «Огней», просмотрена печать: 3 страницы, общая верхняя панель отсутствует в печатном документе.
- Открыт отчёт «Раменок», просмотрена печать: 2 страницы с исходными фотографиями, общая панель отсутствует в печатном документе.

- Просмотрена узкая рабочая область с мобильным нижним меню. Проверка на физическом iPhone/iPad и в Safari standalone ещё не выполнена.

## Проверка Claude

Claude получил только задание и код новой общей оболочки. Исходные большие HTML, финансовые данные, фотографии и архивы ему не передавались.

[Обсуждение в Claude](https://claude.ai/chat/3d0fa03b-8e9e-4c9f-94a3-5d048c56fd5d) содержит проверку чтением кода; Claude не запускал браузер и не редактировал местные файлы. Codex проверил замечания, внёс исправления и выполнил проверки.

Применены замечания о фоновой записи кэша, восстановлении при 5xx, перенаправлении адресов без слэша, ограничении смещения sidebar экранными стилями и отступе для якорей. Дополнительно скорректирована высота полноэкранного журнала «Огней» с учётом общей панели.

Общее предупреждение после любого ввода не добавлялось: в «Огнях» поля управляют фильтрами и параметрами отчёта, а формы редактирования «Раменок» открываются поверх панели в модальном слое с большим z-index. Сохранение данных и поведение исходных форм сохранены. Ограничения хранения новых фотографий и миграции между доменами описаны в README.

## Границы проверки

Не проверены боевой адрес Timeweb, DNS/HTTPS домена, обновление установленной PWA на физических устройствах и фактический ответ Claude на новый отчёт. Общей серверной базы нет; ИИ-сценарий зависит от среды Claude, а подтверждённые добавления хранятся только в текущем браузере.
