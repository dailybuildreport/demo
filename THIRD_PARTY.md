# Сторонние ресурсы

Версии библиотек чтения документов сохранены из исходных «Раменок» и включены локально для автономной работы.

| Ресурс | Версия / лицензия | Файлы |
| --- | --- | --- |
| PDF.js | 3.11.174 / Apache-2.0 | `public/assets/vendor/pdf.min.js`, `pdf.worker.min.js`, `pdfjs-LICENSE.txt` |
| SheetJS | 0.18.5 / Apache-2.0 | `public/assets/vendor/xlsx.full.min.js`, `xlsx-LICENSE.txt` |
| Mammoth | 1.6.0 / BSD-2-Clause | `public/assets/vendor/mammoth.browser.min.js`, `mammoth-LICENSE.txt` |
| Inter | SIL Open Font License | `public/assets/fonts/*.woff2`, `inter-OFL.txt` |
| Playfair Display | SIL Open Font License | `public/assets/fonts/*.woff2`, `playfairdisplay-OFL.txt` |

Фотографии и исходные значки «Раменок» взяты из пользовательского архива. Обложка проекта использует точную копию первой встроенной фотографии. Знак БЦ «Огни» — переданный пользователем `icon-512.png`; он остаётся отдельным от знака DSFlow. Новый знак DSFlow выполнен в SVG по предоставленному визуальному референсу и экспортирован в PNG/ICO.
